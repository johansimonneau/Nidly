Politique de confidentialité

Dernière mise à jour : septembre 2026

Le plus simple à retenir : Nidly ne collecte aucune donnée personnelle, que ce soit sur le site ou dans l'application. Il n'y a pas de serveur auquel envoyer quoi que ce soit.

L'application Nidly

L'application n'a pas de backend : toutes les informations que tu saisis (profil enfant, candidatures, notes, checklist) sont stockées uniquement en local sur ton appareil (technologie Hive). Rien n'est envoyé sur un serveur, il n'y a pas de compte à créer, et personne d'autre que toi n'a accès à ces données — y compris l'éditeur du site.

Si tu désinstalles l'application ou effaces les données de ton navigateur, ces informations sont définitivement supprimées : elles n'existent nulle part ailleurs.

Le site web et le blog

Le site (johansimonneau.github.io/Nidly) ne dépose aucun cookie de suivi et ne charge aucune ressource tierce (polices, scripts, images) depuis un autre domaine que GitHub Pages — y compris les polices d'écriture, hébergées directement sur ce site plutôt que via un CDN externe.

Le seul élément stocké dans ton navigateur est une préférence locale (le fait d'avoir fermé le bandeau d'information sur les cookies), via le localStorage de ton navigateur — jamais transmise à qui que ce soit.

Le site n'utilise aucun outil d'analyse d'audience (pas de Google Analytics ni équivalent) et ne dépose aucun cookie publicitaire.

Hébergement

Le site est hébergé par GitHub Pages (GitHub, Inc.), qui peut recevoir des informations techniques standards de connexion (adresse IP, navigateur) dans le cadre normal du service d'hébergement — cette collecte est faite par GitHub, pas par Nidly, et n'est pas exploitée par l'éditeur du site.
